Aurora Pro for Android TV

A design-parity mockup of a native Android TV app, built from the live web SPA's own design tokens — the same near-black #050505 canvas, the #A855F7 aurora purple, the violet→cyan logo mark, the NOVA typeface pairing (Sora display + Inter Tight body), the glass rails and the cinematic poster cards. How this maps to the web app (and to a real build)

Color & glow

Same tokens: bg #050505, primary #A855F7, secondary text rgba(220,220,232,.65), and the exact --glow-halo / --glow-border shadows from index.css.

Logo mark

The violet→cyan circle + white play triangle is the literal favicon.svg / auroraMark gradient (#A855F7 → #7C3AED → #22D3EE).

Type

NOVA default — Sora display + Inter Tight body. The other three systems (Classic / Eclipse / Halo) live in the Settings screen exactly as the web app exposes them.

Icons

Inline SVGs are the same Feather/Lucide paths shipped in Icon.tsx (home, film, tv, star, library, settings, search, play…).

Cards & rails

The glass rail header (tinted icon chip + title + fading divider + “See all”) and the cinema card (lib badge, AI gem, quality badges, progress, shelf meta) mirror MediaCardCinema / MediaRail.

TV adaptation

Hover → focus: a bright white + purple --focus-ring and a lift/scale replace mouse hover. The sidebar becomes a collapsible icon rail that expands on focus. Everything is 1280×720, 16:9.

Build target

Recommended native stack: Jetpack Compose for TV (or Leanback) with Media3 / ExoPlayer for HLS direct-play + transcode fallback. Each screen here maps to a Compose route; the design tokens become a Compose Theme.

Alternative

Because the SPA is already responsive React, a TV-WebView wrapper with D-pad focus handling could ship parity fastest, reusing this exact CSS.
