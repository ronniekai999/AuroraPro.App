Aurora Pro for Android TV

A design-parity mockup of a native Android TV app, built from the live web SPA's own design tokens — the same near-black #050505 canvas, the #A855F7 aurora purple, the violet→cyan logo mark, the NOVA typeface pairing (Sora display + Inter Tight body), the glass rails and the cinematic poster cards. It is re-laid-out for the 10-foot living-room experience: a focusable left nav rail, D-pad focus rings, and larger type, all at native 1280×720 (16:9). Thirteen screens cover the full web feature set — sign-in & OAuth, profiles, the personalized home, semantic search, movie & episode detail, Catch Me Up recaps, the player with Smart Skip, watch parties, requests, collections, the calendar, and the admin panel.

How this maps to the web app (and to a real build)

Color & glow

Same tokens: bg #050505, primary #A855F7, secondary text rgba(220,220,232,.65), and the exact --glow-halo / --glow-border shadows from index.css.

Logo mark

The violet→cyan circle + white play triangle is the literal favicon.svg / auroraMark gradient (#A855F7 → #7C3AED → #22D3EE).

Type

NOVA default — Sora display + Inter Tight body. The other three systems (Classic / Eclipse / Halo) live in the Settings screen exactly as the web app exposes them.

Icons

Inline SVGs are the same Feather/Lucide paths shipped in Icon.tsx (home, film, tv, star, library, settings, search, play…).

Cards & rails

The glass rail header (tinted icon chip + title + fading divider + “See all”) and the cinema card (lib badge, AI gem, quality badges, progress, shelf meta) mirror MediaCardCinema / MediaRail.

TV adaptation

Hover → focus: a bright white + purple --focus-ring and a lift/scale replace mouse hover. The sidebar becomes a collapsible icon rail that expands on focus. Everything is 1280×720, 16:9.

Build target

Recommended native stack: Jetpack Compose for TV (or Leanback) with Media3 / ExoPlayer for HLS direct-play + transcode fallback. Each screen here maps to a Compose route; the design tokens become a Compose Theme.

Alternative

Because the SPA is already responsive React, a TV-WebView wrapper with D-pad focus handling could ship parity fastest, reusing this exact CSS.

Auth & OAuth

The Sign In card mirrors the web LoginView — cookie JWT + refresh, Argon2, invite codes, and exactly the providers setupStatus can enable: Google, Discord, Twitch, Facebook, X.

Watch parties

The cinematic overlay is the web's minimal party mode: CinematicChatTicker, ReactionOverlay, VoicePill, MiniDock, and the PartyInvite 6-char code + server-rendered QR (/v2/join/CODE).

Local AI

Semantic search (pgvector + Ollama, trigram fallback, the “Smart” badge), Catch Me Up recaps (RecapModal), AI flagged-match review, and the personalized hero — all run on the server, none require cloud calls.

Smart Skip

The player's “Skip Intro” pill is VideoPlayer.tsx's skipLabel (Intro / Recap / Credits) from the sandboxed skip-marker analysis workers; credits trigger the Next-Episode card.

Requests

Row badges use RequestsView's exact status palette — pending (amber), pending_approval (orange), processing (blue), available (emerald), failed (red) — plus 4K/1080p flags and inline admin approval.

Admin

All 13 web admin tabs appear; the dashboard shows the same stat tiles, live transcode sessions (NVENC vs Direct Play), the flagged-match queue, and the auto-updater's Checking→Pulling→Building→Restarting states.

Not re-drawn

Features covered by these screens' affordances rather than dedicated mocks: taste onboarding (noted on Profiles), trailer modal, bug reporter, notifications panel, backup/restore detail, and casting — a TV app is a cast target, not a sender.
