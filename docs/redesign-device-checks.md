# Web redesign: what to check on real devices

The web app's redesign (pull request #558) was built and reviewed in a cloud
container with headless Chromium on Linux and stubbed server answers. No
iPhone, Android phone, tablet, TV, Chromecast or AirPlay receiver, screen
reader, Safari or Firefox was available there, and neither was a real
library, recommender, watch party or cast session. None of the items below
was exercised on a real device or against a real server; each is something
the code was written to get right and nobody has yet seen working on the
real thing.

Work through the list on real devices, fix or file what is wrong, and delete
this file when it is done.

- **iPhone Safari:** double tap against double-tap zoom; tap-to-play after a blocked autoplay; whether a tap near the bottom pins the bars; picture in picture and whether entering it un-inerts the page behind; native fullscreen; rotation; native HLS playback. For cards and Library's list rows: whether a click follows a long press and closes the sheet it opened, whether long press interferes with scrolling, whether More is reachable by VoiceOver swipe. For the PIN prompt: zoom on focus, the keyboard offered, the caret on the invisible field (a touch caret drag or selection handles may move it without any event the page hears), and whether Keychain offers to fill or save. For the title page and Tonight: the 44px touch areas and the phone hero on a device. For Settings: the native dropdown's picker. For onboarding: the numeric keyboard on the age field.
- **Android Chrome:** bottom sheets and the same touch items; whether the browser's own context menu or the card's long press fires first; keyboard composition in the PIN field; landscape with the toolbar showing (a window shorter than 356px) for the player's lane and the voice pill; the native dropdown's picker; with a Chromecast: double tap reaching the receiver, the speed lock, menus closing on minimise.
- **AirPlay hardware:** the speed lock, picture-in-picture exit, auto-minimise with a menu open.
- **Tablets and touchscreen laptops:** the marker editor as a sheet; bottom sheets beside the party rail; hidden card buttons not taking taps; Library's header and A to Z strip under a finger.
