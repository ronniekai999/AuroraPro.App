What this is built on

Almost all of Mode A's behavior ships today inside PartyPanel.tsx — members, chat, the voice strip, the emoji picker. This is largely a visual + layout project: make it translucent, make it float, add the minimal mode. The honest caveat: heavy backdrop-filter over playing video is a real GPU cost — Aurora's own CSS already flags this — so the plan budgets for a perf + reduced-motion pass.

Already exists

Chat · members · ready

All rendered by PartyPanel today. We restyle the container, not the data flow.

Already exists

Voice strip

Join / mute / leave + speaking-glow chips are wired. Reused verbatim in the rail and condensed into the corner pill.

Already exists

Floating reactions

ReactionOverlay already does the Twitch-style rise. Mode B just keeps it while hiding the rail.

New work

Glass restyle + float/dock

Lower the panel opacity, lift it off the edge, and add a dock⇄float toggle. Mostly CSS + a layout state.

New work

Minimal ticker + corner pill

A new lower-third auto-fading chat ticker, condensed voice pill, and pill dock for the "just the movie" mode.

New work

Auto-hide + perf pass

Idle-hide on no activity, prefers-reduced-motion, and a blur budget so weak GPUs don't drop frames over video.
