UI Mockup · Option B

“Aurora Stage” — content is the UI

A bold departure from the current sidebar app: Aurora Pro reframed as a cinematic streaming service. Every screen keeps the production feature set, DNA and tokens (bg #050505, purple #A855F7, cyan #22D3EE, aurora mark, glass panels, purple glow) — only the layout chrome and art direction change.

Top nav replaces the sidebar. The 8 tabs sit centered in a slim bar; the vertical space the sidebar ate is handed back to artwork, and the app reads like a streaming service, not an admin tool.
Full-bleed pages. Heroes run edge-to-edge and the page background is subtly tinted by the current backdrop (deep violet/blue washes), so every page feels like a stage lit for its content.
Bigger, art-forward cards. Posters grow to 200px+ in rails; progress, library badge, AI gem and quality chips live on the art, with title/meta overlaid cleanly instead of a text shelf below.
Editorial typography. Bricolage Grotesque display (oversized hero titles) paired with Inter for UI — Apple TV / Criterion-grade polish without losing the Aurora glow language.
