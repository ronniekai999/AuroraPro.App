UI Mockup · Option C · 16 screens · 1440×900

Command Deck — the operator’s media server.

Today’s Aurora is a theater. This is the control room behind it. Density is respect: show more, scroll less, never hide a number. Every surface is an instrument panel, every list is a table, and the keyboard is a first-class citizen — Linear × DaVinci Resolve × a flight deck. There is no display face and no glow anywhere in the chrome; hierarchy is weight, size steps and drawn 1px lines, and all the romance is left to the content art itself.

Same features, different soul. Every capability of the production SPA — auth & OAuth, onboarding, profiles with parental ceilings, AI hero + Discover rails, semantic search, watch parties (live, scheduled, voice, QR invites), requests, collections, calendar, social follows, gamification, the full 13-tab admin — is drawn on these screens or pinned with a numbered annotation. Nothing was dropped as out of scope.
