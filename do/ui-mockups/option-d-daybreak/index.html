“Daybreak” — soft daylight on paper

The media server as a quiet morning room. Today's Aurora is a midnight theater; Daybreak flips every choice — light where it is dark, soft where it is theatrical, quiet where it is cinematic. Content sits like books on a warm shelf; the interface whispers and gets out of the way. It reads like a beautifully-made reading app that happens to play films.

Same features, different soul. Every user-visible feature of the production app — all 223 checklist items, every rail, badge, state, toast and admin tab — is drawn on these sixteen screens or pinned to one by a numbered callout. Where Daybreak softens a number into words, the exact numeral still lives in a tooltip or detail panel: parity of information, gentler presentation.
